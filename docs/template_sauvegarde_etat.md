## 📋 Instructions d'utilisation du template

### Comment utiliser ce template

1. **Copiez ce fichier** vers un nouveau fichier avec le nom `[nom_projet]_sauvegarde_etat.md`
2. **Remplacez tous les placeholders** entre crochets `[PLACEHOLDER]` par les valeurs réelles
3. **Adaptez les sections** selon les besoins spécifiques de votre projet
4. **Supprimez les sections** non pertinentes pour votre contexte
5. **Ajoutez des sections** spécifiques si nécessaire

### Placeholders à remplacer

- `[NOM_DU_PROJET]` : Nom du projet
- `[YYYY-MM-DD]` : Date au format ISO
- `[X.Y.Z]` : Version sémantique
- `[Nom - Rôle]` : Nom et rôle du mainteneur
- `[X]%` : Pourcentage d'avancement
- `[Catégorie]` : Nom des catégories de fonctionnalités
- `[Fonctionnalité]` : Description des fonctionnalités
- `[État actuel]` : Description de l'état actuel
- `[chemin/vers/fichier]` : Chemin vers les fichiers importants

### Sections optionnelles à adapter

- **Métriques du projet** : Adaptez selon les métriques importantes pour votre projet
- **Décisions architecturales** : Ajoutez/supprimez selon la complexité du projet
- **Phases de développement** : Adaptez selon votre roadmap
- **État technique détaillé** : Adaptez selon les composants techniques de votre projet

### Bonnes pratiques

- **Mettez à jour régulièrement** : Cette sauvegarde doit refléter l'état réel du projet
- **Soyez précis** : Utilisez des pourcentages et des métriques concrètes
- **Documentez les décisions** : Les décisions architecturales sont importantes pour la maintenance
- **Planifiez les prochaines étapes** : Ayez une vision claire de la roadmap
- **Notez les dépendances** : Important pour la maintenance et la migration
